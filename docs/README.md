# Project Documentation: Chat & GraphQL System

Welcome to the technical documentation for the Rock Stars theme chat integration. This system provides a seamless bridge between a WordPress backend, a Telegram bot for administrative responses, and a modern React (Next.js) frontend.

## 📖 Table of Contents

1.  **[System Architecture](architecture.md)**
    *   Learn how messages flow between the Frontend, WordPress, and Telegram.
2.  **[GraphQL API Documentation](graphql-api.md)**
    *   Details on types, queries (`chatHistory`, `chatStatus`), and mutations (`sendChatMessage`).
3.  **[Installation & Local Setup](installation.md)**
    *   Step-by-step guide to setting up Ngrok, Telegram Bots, and the local development environment.
4.  **[Database & Metadata](database.md)**
    *   Reference for Custom Post Types (`qa`, `ticket`) and metadata keys.

## 🚀 Getting Started

If you are just starting, we recommend reading the **[Installation Guide](installation.md)** first to get your local environment (Ngrok + WordPress + React) connected properly.
