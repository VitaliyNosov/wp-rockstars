How it works:

The three dots blink sequentially (1→2→3) using CSS keyframe animation. Each dot has the same animation but with staggered delays:

• Dot 1: 0s delay
• Dot 2: 0.2s delay
• Dot 3: 0.4s delay

This creates a smooth, professional loading indicator that draws the eye and clearly communicates that a process is ongoing.
